Learning outcomes

This module covers the core ideas of object-oriented programming in Python: classes and objects, encapsulation, inheritance, polymorphism and abstraction. It also covers design patterns, SOLID principles, version control with Git, and testing and debugging, with a focus on software that uses resources responsibly.

Artefacts

Online Shopping System (assessed coursework)

Python code, slide deck and vodcast script

A Python online shopping system built around a three-level class hierarchy (User, Customer and PremiumCustomer). It uses an abstract base class (Orderable) to set out what can be ordered, property validators to protect each object's data, and a demonstration of polymorphism. I presented it in a 14-slide deck with a vodcast script.

Summative Assignment 2: practical test

Python code and short written answers

A plugin system for a text editor using the Singleton pattern (one PluginManager) and the Observer pattern (plugins such as a spell checker and grammar checker reporting their status back). It also includes a Task class with input validation, a unittest test suite for it, and short written answers on modularisation, using Git in a team, and code reviews.
